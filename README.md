# OUR LITTLE WORLD ❤️👻

## 1. Run it
Open `index.html` in Chrome. (Everything is local; only the Google Fonts link needs internet, with fallbacks if offline.)

## 2. Add your photos
Put JPGs in `assets/images/`, then edit the `PHOTOS` list at the top of `script.js`. Change `FIRST_MEETING_PHOTO` to your March 10 photo. Visitors can also tap **Add photos** (saved in the browser when it allows).
Your 9 uploaded photos are already in as `photo1.jpg` – `photo9.jpg`.

## 3. Change messages
Top of `script.js`: `FIRST_TEXT`, `LETTER`, `FINAL`. Headings are in `index.html`.

## 4. Music
Put any free/royalty-free song at `assets/music/song.mp3`. Music starts only when she taps 🎵.

## 5. Android
Copy the folder to your phone, open `index.html` in Chrome (Files app → Open with Chrome). For the easiest way, use GitHub Pages and share the link.

## 6. GitHub Pages (free)
1. Create a GitHub repo, upload all files (keep the folder structure).
2. Settings → Pages → Source: `main` branch, `/ (root)` → Save.
3. Open `https://YOUR-NAME.github.io/REPO-NAME/` after a minute.
